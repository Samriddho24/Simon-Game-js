# Simon Game 🎮

An interactive memory game inspired by the classic Simon Game, built using HTML, CSS, JavaScript, and jQuery.

## 🚀 Live Features

- Random color sequence generation
- Dynamic level progression
- Sound effects for each color
- Button press animations
- Game-over detection
- Restart functionality
- Responsive and interactive UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- jQuery

## 🎯 How to Play

1. Press any key to start the game.
2. Watch the sequence displayed by the game.
3. Repeat the sequence by clicking the colored buttons.
4. Each level adds a new color to the sequence.
5. The game ends when you click the wrong color.
6. Press any key to restart after a game over.
